# 共享密度域 LUT

更新：2026-09-23。本文描述已上线的移动端结构。

## 管线

```text
sRGB → 胶卷 raw 表 / 柔光场 → 散射与线性加性 halation → 曝光与黑白校正
     → log exposure → 显影曲线 + DIR（应用默认开启空间扩散）→ 密度颗粒
     → 密度预变换 W → 共享印相或直扫表 → 扫描锐化 / glare → 输出
```

印相链依赖胶卷染料光谱，不能把同一密度三元组直接交给任意载体共享表。W 将该胶卷密度映射为基准胶卷的等价密度，再进入共享表。全局密度域为 `[-0.45, 3.55]`，采样坐标为 `clamp((W(d) + 0.45) / 4)`。

当前应用关闭自动测光，默认柔光为 CineBloom 1/8。柔光和空间 DIR 的有界场近似及设备验证范围见 [运行状态](public-runtime-status.md)。

## 当前规模

- 14 款彩负 × 8 种彩色载体，W 为 3×10 二次多项式。基准卷自身恒等。Endura 系以 Portra 400 为基准，Crystal Archive 以 Superia 为基准，2383／2393 以 Vision3 250D 为基准。
- Double-X × Kodak 2302 使用单通道印相表，无需彩色 W。
- 4 款彩色反转片共用 Velvia 基准直扫表；其余三款用 3×20 三次 W，Velvia 恒等。
- Tri-X 保留逐款扫描表，不进入彩色共享分支。

共 20 款胶卷、118 种组合。印相表通常 41³，Kodak 2393 为 53³；彩色直扫表为 41³。具体文件、尺寸和数值指纹在 `styles/presets-prints.js`、`styles/presets-scans.js` 中。

二次特征顺序为 `[1,r,g,b,r²,g²,b²,rg,rb,gb]`；三次特征继续追加 `[r³,g³,b³,r²g,r²b,g²r,g²b,b²r,b²g,rgb]`。注册表按 3 行展开存储。密度曲线与 DIR 在运行时只执行一次，共享表不再烘入第二次 DIR。

## 校准与验收

拟合在胶卷可达密度域内取样。直扫拟合显式模拟运行时钳位，避免越界密度在拟合时看似准确、采样时被截断。发行使用已保存的系数，再拟合属于模型变更。

数值裁判以固定上游的密度到扫描链为真值：MAE ≤ 1、P99 ≤ 4、max ≤ 12，单位均为 8 位码值；任一失败会使脚本非零退出。浏览器完整门禁另行覆盖 LUT 采样、光学场、自检与颗粒统计。共享表色彩门禁不等价于完整照片或实体胶片还原认证。

重建命令及开发环境见 [构建与复现](public-build.md)。
